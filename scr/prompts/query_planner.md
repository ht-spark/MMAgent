## 你的任务

为每个**高优先级（high）**缺口生成 **中英文双语查询组**（每种语言 2-3 条），为**中优先级（medium）**缺口至少生成 1 条查询。每条查询包含：

2. **purpose**：搜索目的（说明这条查询要解答什么）。
3. **language**：查询语言（"zh" 或 "en"）。
4. **source_preference**：偏好来源类型（academic_paper / official_standard / government_data / research_report / any）。

## 查询编写原则

- 使用领域术语，避免口语化表达。
- 中英文查询应有差异（中文查询适合政府/标准数据，英文查询适合学术论文）。
- 不要将完整题目作为唯一查询（太宽泛，无搜索价值）。
- 每条查询独立，可单独执行搜索。
- 至少生成 5 条查询（高优先级缺口 × 双语 + 中优先级补充）。

## 优先级策略

- `high` 优先级 → 必须双语（中 + 英）
- `medium` 优先级 → 至少一种语言
- `low` 优先级 → 可以忽略（不强求生成查询）
