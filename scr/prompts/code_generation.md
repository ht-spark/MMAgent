## Nature 风格科研绘图契约

绘图不是结果装饰，而是对核心建模结论的可核查证据。生成代码前先在内部完成以下判断，不要额外输出分析文字：

1. 用一句话确定图要支持的核心结论，并指定唯一的主证据图。
2. 为每个候选面板定义不同的证据作用；不能增加新信息的面板必须删除。
3. 默认采用 `quantitative grid`（定量证据网格）；只有存在互补证据时才使用非对称多面板布局，并突出一个主面板。
4. 检查审稿风险：样本量、误差条或置信区间含义、坐标单位、比较基准、异常值和约束是否能够从图中辨认；不得虚构数据、重复实验、显著性或置信区间。

绘图代码必须遵守：

- 在导入 `pyplot` 前调用 `matplotlib.use("Agg")`，适配无界面执行环境。
- 统一使用白色背景和简洁无衬线字体；中文标签必须可正常显示，设置字体回退优先包含 `Microsoft YaHei`、`SimHei`、`Noto Sans SC`，再包含 `Arial`、`DejaVu Sans`、`Liberation Sans`，基础字号建议 8–10 pt。
- 隐藏顶部和右侧坐标轴，轴线简洁，图例无边框；避免装饰性边框、阴影、渐变、3D 柱状图和高饱和彩虹色。
- 同一方法或场景在所有面板中保持相同颜色。主方案优先使用深蓝 `#0F4D92`，基线使用灰色系；绿色和红色只用于明确表示改善/下降、正/负偏差或约束越界。
- 优先直接标注稳定类别；仅在确有必要时使用图例。多面板共享图例，面板编号使用左上角小写粗体 `a`、`b`、`c`。
- 坐标轴必须写清变量名和单位。误差条、置信区间和参考线必须基于真实计算结果，并通过标题、标签或图例说明含义。
- 柱状图比较绝对量时原则上从零开始；折线图、散点图和残差图可以根据数据范围合理收紧坐标轴，但不得通过截断夸大差异。
- 多面板图中每个面板必须回答不同问题，例如“总体表现—偏差/残差—稳健性”，禁止把同一组数据换一种图形重复展示。
- 对颜色之外再使用线型、标记或纹理区分类别，保证灰度打印和色觉缺陷场景下仍可辨认。
- 使用 `fig.tight_layout()` 或 `constrained_layout=True` 防止文字裁切；PNG 以 `dpi=300`、`bbox_inches="tight"`、非透明背景保存，密集图可使用 600 dpi。
- 每次 `savefig` 后立即 `plt.close(fig)`；文件名使用简短英文 `snake_case`，不得覆盖其他图。
- 若数据不足以支持误差分析、多面板或统计标注，应输出信息充分的单图，不得补造证据。
