## 分析要求

请完成以下五步本质判断：

1. **确定性结构（determinism）**：本问是确定性问题（所有参数、运动规律、
   关系全部给定，答案唯一且可直接计算）、随机性问题（含随机变量、不确定性
   或噪声，必须借助统计/抽样/仿真），还是混合问题？
   - 关键判别：**题目是否给出了全部数值参数**（速度、坐标、时间、几何尺寸等）？
     全给定且不含随机因素 → deterministic，哪怕题目涉及"过程演化"。
   - 只有存在真实的随机输入、分布假设或需要统计推断时才是 stochastic。

2. **可解析性（solvability）**：能否通过建立方程/几何关系/解析表达式直接
   求出精确解（analytic），还是必须依赖数值迭代/优化求解器（numeric），
   还是确实需要随机抽样仿真（simulation_required）？
   - 判别要点：答案若能从"列方程 → 代入数值 → 求根/求交/求区间"得到，
     应判 analytic；仿真只在解析路径走不通时才允许。

3. **数学结构（structure_tags）**：本问的核心数学对象是什么？
   如：运动方程、几何相交、优化目标与约束、统计分布、网络流……
   用 2-5 个短语概括。

4. **推导路径（derivation_plan）**：给出 3-6 步的求解推导思路，
   每步说明"建立什么 → 求什么"（例如：建立各对象运动方程 →
   建立遮蔽的几何判定条件 → 解析求出临界时刻 → 与有效窗口取交集）。
   这一步是后续建模与代码生成的纲领，必须具体到可操作。

5. **答案形式（answer_form）**：题目要求的最终产出是什么？
   一个数值、一个时间区间、一张最优方案表、一个排名……必须具体。

## 输出要求（严格使用给定字段名，输出纯 JSON）

- determinism: deterministic / stochastic / mixed
- solvability: analytic / numeric / simulation_required
- structure_tags: 数学结构标签数组（2-5 个短语）
- derivation_plan: 推导路径数组（3-6 步，每步一句）
- answer_form: 最终答案形式（一句话）
- reasoning: 上述判断的依据（2-4 句，必须引用题目中的具体条件）
