## 题型定义

请从以下类型中选择主类型（恰好一个）和次类型（零或多个）：

| 类型 | 代号 | 典型特征 |
|------|------|----------|
| 综合评价 | evaluation | 多指标排序、权重分配、优劣评估 |
| 预测 | prediction | 时间序列预测、回归预测、趋势外推 |
| 优化 | optimization | 线性规划、整数规划、非线性优化、资源分配 |
| 分类 | classification | 聚类、判别、模式识别 |
| 仿真 | simulation | 系统模拟、蒙特卡洛、动态过程 |
| 机理分析 | mechanism | 建立物理/数学机理模型、微分方程 |
| 综合 | composite | 以上多种类型混合，无法归入单一类型 |

## 你的任务

1. **primary_type**：选择一个最核心的题型代号。如果任务明显涉及多种类型且无法区分主次，选 "composite"。

2. **secondary_types**：列出涉及但非核心的题型代号（可为空列表）。

3. **reasoning**：用 2-4 句话说明分类理由，包括：
   - 为什么选这个主类型
   - 任务的哪些特征支持这个判断
   - 如果有次类型，为什么它们不是主类型

## 注意

- 分类基于任务的**本质任务**，不是基于可能使用的模型。
- 一道题允许"一主多次"（如主类型 evaluation，次类型 prediction）。
- 如果任务明确要求"建立 XX 模型"，以模型对应的任务类型为准。
